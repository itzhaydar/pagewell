# On-Device-OCR-PDF

> **Photo of a page → searchable PDF. On-device. No upload.**

On-Device-OCR-PDF is a static browser app that turns a photo or scan of a printed page into a searchable PDF. OCR runs locally in the browser with Tesseract.js, and PDF creation runs locally with pdf-lib. There is no backend, account, API key, document upload, cloud storage, or document analytics. It is designed to be hosted directly from a GitHub Pages repository.
